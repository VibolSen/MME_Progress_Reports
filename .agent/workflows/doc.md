# /doc Workflow

**Author:** Docs Specialist  
**Date:** 2026-11-11  
**Task:** Slash Command Setup - doc (workflow)  

1. Target documentation in `team/`, `tasks/`, `AGENTS.md`, `GEMINI.md`, or `app/slidesData.ts`.
2. Ensure mandatory header (Author, Date, Task) is present on every file.
3. Synchronize both Khmer and English copy.
4. Run `npm run format` and `npm run lint`.
