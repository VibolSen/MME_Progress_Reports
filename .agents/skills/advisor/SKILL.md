# /advisor · Strategic Advisory & Stakeholder Workflow

**Author:** Advisor Specialist  
**Date:** 2026-11-11  
**Task:** Slash Command Setup - advisor  

Use this command when evaluating strategic alignment with the Ministry of Mines and Energy (MME), addressing inter-ministerial coordination, or planning departmental roadmaps.

## Workflow Instructions
1. **Scope & Strategic Assessment:**
   * Review MME requirements, current milestone status, and pending items in [`app/slidesData.ts`](../../app/slidesData.ts).
2. **Key Advisory Protocols:**
   * **Payroll Inter-Ministerial Coordination:** Formulate guidance for joint sessions between MME and MEF / civil service focal points.
   * **Scope Intake for Departments 2 & 3:** Plan intake workshops and data normalization to transition them from "In Pipeline" to active components.
   * **Executive Narrative:** Ensure the 3 core pillars (Progress & Pending, Challenges, Expected Completion) are clearly articulated.
3. **Documentation:**
   * Record strategic recommendations in `team/advisor/` and update slide data accordingly.
4. **Post-Edit Formatting:**
   ```bash
   npm run format
   ```
